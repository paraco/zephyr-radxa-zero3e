# L5b — Gated Attention 층 관문 (합성 가중치)

[docs/llm-hub-test-plan.md](../../docs/llm-hub-test-plan.md) 의 사다리 L5b.
치수는 Qwen3.5-0.8B **실측값**: `head_dim=256 · n_head=8 · n_head_kv=2`(GQA 4:1)
· `n_rot=64`(부분 RoPE) · `sections=[11,11,10,0]`(mRoPE) · `freq_base=1e7`.

## ⚠ 가리는 것과 가리지 못하는 것

가중치가 합성이다. **"ggml 이 이 층을 호스트와 똑같이 계산하는가"** 만 가린다.
**"llama.cpp 의 `qwen35` 경로가 옳은가" 는 아니다.**

## 오차가 어디서 들어와 어떻게 커지는지 — **측정했다**

`[15]` 가 9,287 ppb 로 나머지(100~400 ppb)보다 컸다. "sigmoid 때문일 것" 이라고
추론하는 대신 **sigmoid 전후를 모두 비교 대상에 넣어** 가렸다.

| 지점 | 결과 | 읽는 법 |
|---|---|---|
| `[13]` sigmoid **전** | **전체 비트 일치** | 여기까지는 완전히 같다 |
| `[14]` sigmoid **후** | 19/1024, **154 ppb** | **오차의 입구가 sigmoid(libm)** 다 |
| `[15]` `wo` 투영 (2048항 내적) | 302/1024, **9,287 ppb** | 1 ulp 가 2048항 합에서 약 **60배** 퍼진다 |

**L6 에 바로 쓰이는 사실이다.** 층 **하나**의 출력이 이미 1e-5 로 벌어진다.
24층을 지나면 값 비교는 의미가 없다. 그래서 계획서가 L6 판정을
**"상위 k 토큰 일치"**, L7 을 **"토큰 열 완전 일치"** 로 둔 것이 옳다 —
이제 그 이유를 숫자로 말할 수 있다.

## 부분 RoPE — 숫자로 확인했다

`rope.dimension_count = 64` 인데 `head_dim = 256` 이다. 앞 64 만 회전하고
나머지 192 는 그대로여야 한다. RoPE 전후가 달라진 자리를 모든 토큰·헤드에
걸쳐 셌다:

```
lo (차원 [0,64))    = 1491  개 변함
hi (차원 [64,256))  =    0  개 변함   ← 이것이 핵심이다
```

**⚠ 내가 한 번 오독했다.** 처음에는 **토큰 0 만** 봤고 `lo=0 hi=0` 이 나와
"RoPE 가 아예 안 걸렸다" 로 읽었다. 틀렸다 — **위치가 0 이면 `theta=0` 이라
`cos=1`·`sin=0` 이고 회전이 항등**이다. 전체 토큰으로 넓히자 `lo=1491` 이 됐다.

mRoPE 의 위치 배열은 **구간별**이다 — `p_t = pos[i2]`, `p_h = pos[i2 + ne2]`
(`ggml-cpu/ops.cpp:6403-6404`). 그리고 **토큰당 위치 id 4개**를 요구한다
(`ggml.c`: `a->ne[2] * 4 == b->ne[0]`).

## 함정 — Q 와 게이트가 **헤드마다 교차** 배치돼 있다

결합 QG 투영의 결과에서 헤드당 블록이 `2 × head_dim` 이고 **앞 절반이 Q,
뒤 절반이 게이트**다. 보폭 있는 `view_3d` 로 뽑는다
(`qwen35.cpp:283-302`):

```c
q    = view_3d(qg, HD, NH, NT, es*HD*2, es*HD*2*NH, 0);
gate = view_3d(qg, HD, NH, NT, es*HD*2, es*HD*2*NH, es*HD);
```

**앞 절반 전체가 Q, 뒤 절반 전체가 게이트인 것이 아니다.** 그렇게 읽으면
형태는 맞고 값이 섞여 **조용히 틀린다.** `[1]`·`[2]` 가 축 배치를 값보다
먼저 보는 이유다.

## 게이트 함수가 L5a 와 다르다

| | 함수 | 출처 |
|---|---|---|
| L5a `ssm_norm` 뒤 | **`silu`** | `qwen35.cpp:252-261` |
| L5b 어텐션 뒤 | **`sigmoid`** | `qwen35.cpp:322-325` |

같은 파일 안에 둘이 다 있어 헷갈리기 쉽다.

## 어텐션 본체는 비-flash 경로를 옮겼다

`llama-graph.cpp:3084-3141`:

```
kq  = mul_mat(k, q)                      /* GQA: q->ne[2] % k->ne[2] == 0 로 전파 */
kq  = soft_max_ext(kq, mask, 1/sqrt(HD), 0)
kqv = mul_mat(v_t, kq)                   /* KV 캐시의 v 는 전치돼 있다 */
cur = permute(kqv, 0,2,1,3)
cur = cont_2d(cur, ne0*ne1, ne2*ne3)
```

마스크 규약(`ggml.c:4213-4220`): `ne0 == kq->ne0`, `ne1 >= kq->ne1`, 연속,
F32 또는 F16.
